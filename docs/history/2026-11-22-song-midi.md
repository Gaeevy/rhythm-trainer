# 2026-11-22 — MIDI accompaniment for songs

[Lessons](../lessons.md#add-a-song-excerpt) describes how to prepare a song
excerpt and pair its MIDI file with the lesson JSON.

- Song arrangements moved into separate MIDI clips. The clip's explicit
  length preserves trailing rests and can span several drum loops.
- Pitched notes retain their timing in the file's own resolution. The
  practice BPM and shared audio origin keep the clip aligned with the drums.
- Exercises continue to use the generator. Timed chord changes remain
  available in generated harmony.
