# 2026-11-05 — Practice toolbar

Historical summary. Current controls are described in [Practice](../practice.md).
The original plan and intermediate reviews remain in Git history.

- Repeated lesson headings and routine hints were removed to give practice more
  space. Notation became the default; view selection and the drum key moved into
  folded Practice settings.
- Lesson, integer/logarithmic BPM, guide/metronome volumes and transport shared
  one row. A reset icon restored the lesson tempo; saved fractional tempos were
  migrated without losing other preferences.
- Joined staff edges and density-based one-to-three-bar rows replaced separated
  cards. Accessible feedback and visible errors remained.
- A master-volume experiment was later removed. The final mixer used separate
  logarithmic sliders, with metronome gain up to 300% and no master control.

At the initial checkpoint, 132 Node tests and 26 browser scenarios passed at
both deployment paths. Later mixer and analytics changes superseded parts of
that checkpoint; use the current guide and Actions runs for present behavior.
